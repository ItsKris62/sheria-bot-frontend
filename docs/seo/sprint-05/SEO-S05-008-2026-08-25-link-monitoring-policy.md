## 1. Inbound Link Classification Framework

To protect domain authority and search integrity, inbound referring domains are categorized as:

| Classification | Definition | Example Source Types | Action Protocol |
| :--- | :--- | :--- | :--- |
| **`TRUSTED`** | High-authority, editorially verified institutions | Universities, government/regulator publications, top-tier media | Maintain relationship & monitor |
| **`RELEVANT`** | Niche tech/fintech blogs, startups, directories | Regional fintech newsletters, incubator portfolios | Engage & explore reciprocal value |
| **`NEUTRAL`** | Aggregators, automated indexers, standard scraping | Search engines, generic business listings | No action required |
| **`LOW_QUALITY`** | Scraped content farms, low-value auto directories | Auto-generated blog aggregators | Monitor passively |
| **`SUSPICIOUS`** | Malicious PBNs, link schemes, deceptive anchors | Obvious link spam / toxic link networks | Investigate pattern |

---

## 2. Disavow Safeguard Rules

* **Conservative Disavow Policy:** Google's search algorithms ignore benign low-quality links automatically. Disavow submissions via Google Search Console are reserved exclusively for severe manual action warnings or proven large-scale negative SEO attacks.
* **Prohibition:** Zero proactive mass-disavowing of normal scraper or aggregator links without explicit legal/SEO review.
